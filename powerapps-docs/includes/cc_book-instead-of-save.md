> [!NOTE]
> The `OnSave` event for [appointment](../developer/data-platform/reference/entities/appointment.md), [recurring appointment](../developer/data-platform/reference/entities/recurringappointmentmaster.md), or [service activity](/dynamics365/developer/reference/entities/serviceappointment) records cancels the save operation and uses the [`Book`](xref:Microsoft.Dynamics.CRM.Book) message to save the change instead of `Create` or `Update`. Because of this behavior, `OnSave` and `PostSave` event handlers for these tables don't work.
