# Get started with the Dataverse Web API (C#)

This article introduces simple ways to access the Dataverse Web API with C#. Use the console and Blazor Server quickstart samples to connect to Dataverse and retrieve data.

- [Quick Start: Web API sample (C#)](quick-start-console-app-csharp.md) provides the quickest example of how to access data, as all source code is simplified and provided in one file.
- [Quickstart: Blazor Server Web API sample (C#)](quick-start-blazor-server-app.md) shows how to create a web application that can connect to Dataverse and retrieve data by using the Web API.


To learn more, explore the [Web API Samples (C#)](web-api-samples-csharp.md).
