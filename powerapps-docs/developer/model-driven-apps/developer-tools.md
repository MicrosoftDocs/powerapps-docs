# Developer tools for model-driven apps

The Microsoft Dataverse community creates developer tools for model-driven apps that simplify customization, configuration, administration, and operations. Many popular tools are distributed through Power Platform ToolBox and XrmToolBox.

## Power Platform ToolBox tools

[Power Platform ToolBox](https://www.powerplatformtoolbox.com) bundles a number of community-created tools in a modern application that [supports multiple platforms](https://www.powerplatformtoolbox.com/versions).

The following list highlights community tools distributed via Power Platform ToolBox that you can use when working with model-driven apps.

| Tool | Description |
|---------|---------|
|[Command Bar Studio](https://www.powerplatformtoolbox.com/tools/ef59cff2-20ae-4521-9bed-0407c4793ea8)| Visual designer for Dataverse classic ribbon and command bar customizations — the spiritual successor to Ribbon Workbench, built for Power Platform ToolBox|
|[Dataverse Request Studio](https://www.powerplatformtoolbox.com/tools/d2a6ec6e-3dfb-4c24-9560-26647168a1f8)| Compose, preview, and execute Microsoft Dataverse Web API requests — a metadata-driven studio for OData queries, record writes, associations, action, function, workflow invocation, and file, image, and attachment operations.|
|[Easy Translator](https://www.powerplatformtoolbox.com/tools/53b614e7-b6b9-4520-a223-c25fcccbe72c)|Export and import translations.|
|[FetchXML Studio](https://www.powerplatformtoolbox.com/tools/e64db554-5dc9-4cc5-a712-832307d00777)| A powerful, modern FetchXML query builder and data explorer for Microsoft Dataverse and Dynamics 365.|
|[PCF Builder](https://www.powerplatformtoolbox.com/tools/fca7fd3c-54e1-4d2f-877c-ca29d1f4cd47)|Build, manage, and deploy Power Apps Component Framework (PCF) controls|
|[Side Pane Studio](https://www.powerplatformtoolbox.com/tools/39275efb-bb2b-4458-b793-5be107fc5caa)|A visual builder for Dynamics 365 and Power Apps model-driven app side panes.|
|[View Layout Copier](https://www.powerplatformtoolbox.com/tools/5d42d392-776c-4ff5-bc0d-65f0492d7ed6)|Copy column layout, sort order, and components configuration from one view to multiple views of the same table in a single operation|
|[Web Resource Manager](https://www.powerplatformtoolbox.com/tools/da709bd7-6874-45c2-994e-2be4aaaa1027)|Manage web resources.|


## XrmToolBox tools

[XrmToolBox](https://www.xrmtoolbox.com/) is a Windows application that connects to Dataverse and includes more than 453 plugins.

The following list highlights community tools distributed through XrmToolBox that you can use when working with model-driven apps.

| Tool | Description |
|---------|---------|
|[Dataverse REST Builder](https://www.xrmtoolbox.com/plugins/GuidoPreite.DRB/)|Generates JavaScript code for use with the Web API. [It's also available outside XrmToolbox](https://github.com/GuidoPreite/DRB)|
|[Easy Translator](https://www.xrmtoolbox.com/plugins/MsCrmTools.Translator/)|Exports and Imports translations with contextual information.|
|[Export to Excel](https://www.xrmtoolbox.com/plugins/Ryr.XrmToolBox.ExportToExcel/)|Easily export records from the selected view/fetchxml to Excel.|
|[FetchXML Builder](https://fetchxmlbuilder.com/)|Build queries for Microsoft Dataverse, Dynamics 365, and the Power Platform. Investigate data. Get code.|
|[Iconator](https://www.xrmtoolbox.com/plugins/MscrmTools.Iconator/)|Manage custom tables icons in a single screen.|
|[Ribbon Workbench 2016](https://www.xrmtoolbox.com/plugins/RibbonWorkbench2016/)|Edit the ribbon or command bar from inside the XrmToolbox.|
|[View Designer](https://www.xrmtoolbox.com/plugins/Cinteros.XrmToolBox.ViewDesigner/)|Easy UI to design view layouts and alter queries using FetchXML builder.|
|[View Layout Replicator](https://www.xrmtoolbox.com/plugins/MsCrmTools.ViewLayoutReplicator/)|Apply same layout to multiple views of the same table in a single operation.|
|[WebResources Manager](https://www.xrmtoolbox.com/plugins/MsCrmTools.WebResourcesManager/)|Manage your web resources easily|


> [!IMPORTANT]
> Tools created by the community are not supported by Microsoft. If you have questions or issues with community tools, contact the publisher of the tool.
